DDOS | PLAYER

VERSION 1 | DUAL DECK OPERATING SYSTEM
OPERATING MANUAL

BASIC OPERATION

1. LOAD TRACKS: Click "CHOOSE FILE" on each deck to load audio files (MP3, WAV, etc.)

2. PLAYBACK CONTROLS:

  • CUE: Hold to preview from cue point, releases returns to cue
  • PLAY: Start continuous playback from current position
  • PAUSE: Stop and set new cue point at current position
  • STOP: Stop playback and return to cue point

MIXING CONTROLS

VOLUME FADERS: Vertical faders above crossfader control each deck's volume (0-100%)

CROSSFADER: Horizontal fader blends between decks. Left = Deck A, Center = Both, Right = Deck B

TEMPO FADERS: Horizontal faders adjust playback speed (±10%). Left = slower, Right = faster

BPM SYNCHRONIZATION

TAP TEMPO: Click the "TAP TEMPO" button on each deck in rhythm with the beat (at least 2 taps). BPM will display above the button.

BEATMATCHING:

  • Tap tempo for both tracks to find their BPMs
  • Use tempo faders to match the BPMs
  • Use CUE button to preview and align beats
  • Use crossfader to transition between tracks

VISUAL FEEDBACK

WAVEFORM: Static overview of entire track

VISUALIZER: Real-time oscilloscope shows current audio

PROGRESS BAR: Click anywhere to jump to that position
